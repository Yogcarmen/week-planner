# 周计划时间轴

一页显示一整周（周六开始），精确到 15 分钟，带当前时间线、预设项目、提前安排（虚线 → 完成后实线）和番茄钟。可以加到手机、平板主屏幕上用，开启 Firebase 后多设备同步。

## 用法

- **五个类别**：备考、PhD申请、找工作、生活琐事、放松。
- **直接记录 / 提前安排**：顶部开关决定新加的项目是哪一种。直接记录是实线；提前安排是虚线，右上角有个圆圈，点一下就算完成，变成实线。提前安排可以先不选类别（灰色「未定」），之后再补。
- **快速插入**：点一个预设标签，再点时间格；可以连续放，再点一次标签取消。
- **拖动**：电脑上直接拖动换时间或换天，拖底边改时长；手机上按住半秒再拖。
- **番茄钟**：右上角「番茄钟」，选类别和时长（默认专注 50 分钟、休息 10 分钟）。专注结束会响铃、弹通知，并自动在时间轴上记一段实线。
- **待办**：右上角「待办」打开清单。可以不定日期，也可以定在某一天；定了日期的会显示在那天的表头里，点一下就打勾。打开一条待办，可以「排进时间轴」，变成那天的一条提前安排。
- **统计**：右上角「统计」，按周或按月看各类别花了多少小时（只算实线），下面还有每天 / 每周的分布和按项目的明细。
- **起床 / 睡觉**：每天表头有太阳和月亮两个小按钮，填上起床和睡觉时间，时间轴上会画出两条线，睡着的时段打上斜纹。统计里，起床到睡觉之间没标的空白算作休息，还会算平均起床、入睡时间和平均睡眠。
- **复制上周**：把上周的内容复制成本周的提前安排。
- **统计**：顶部显示本周各类别的小时数（只算实线），每天表头有当天的分布条。

## 开启多设备同步（Firebase，免费）

不做这一步也能用，只是数据只存在当前浏览器里。做完后，之前记的内容可以一键上传。

1. 打开 <https://console.firebase.google.com>，用 Google 账号登录，点 **创建项目**（名字随便，比如 `week-planner`），Google Analytics 可以关掉。
2. 项目首页点 **</>（Web）** 图标添加网页应用，昵称随便填，**不用**勾选 Firebase Hosting。完成后页面会显示一段 `const firebaseConfig = { ... }`，把整段复制下来。
3. 左侧 **构建 → Authentication → 开始使用 → Sign-in method**，启用 **Google** 和 **电子邮件/密码** 两种方式。
4. 同一页的 **设置 → 已获授权的网域**，点添加，填 `你的用户名.github.io`。
5. 左侧 **构建 → Firestore Database → 创建数据库**，位置选 `eur3 (europe-west)`，选「以正式版模式启动」。创建好后打开 **规则** 标签，整段替换成下面这段，再点 **发布**：

   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{uid}/{document=**} {
         allow read, write: if request.auth != null && request.auth.uid == uid;
       }
     }
   }
   ```

   这条规则的意思是：只有你登录的账号能读写你自己的数据。

6. 把第 2 步复制的配置粘贴到 `firebase-config.js` 里，替换 `null`，变成：

   ```js
   export const firebaseConfig = {
     apiKey: "...",
     authDomain: "...",
     projectId: "...",
     storageBucket: "...",
     messagingSenderId: "...",
     appId: "..."
   };
   ```

   这些值本来就是公开放在网页里的，不是密码；真正保护数据的是第 5 步的规则。

## 加到主屏幕

- **iPhone / iPad**：用 Safari 打开网址 → 分享 → 添加到主屏幕。番茄钟通知需要 iOS 16.4 以上，并且要从主屏幕图标打开。
- **安卓**：Chrome 打开 → 菜单 → 添加到主屏幕 / 安装应用。
- **电脑**：Chrome 或 Edge 地址栏右侧的「安装」图标。

## 关于提醒

网页没法在手机锁屏时准时提醒：浏览器会把后台页面暂停。到点时如果页面开着（电脑上切到别的窗口也算），会响铃加弹通知；手机锁屏的话，回到页面时会立即提醒，并补记那一段专注。
